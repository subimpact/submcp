Built for the edge of the MCP ecosystem

One binary, no runtime

A static Go binary with zero dependencies. No Node, no Python, no 1 GB container images. The Docker image is 15 MB.

Multi-upstream fan-out

One tools/list or tools/call fans out to every registered server. A dead upstream is skipped, the rest still respond.

Namespaced tools

Every tool is prefixed with its server: peecai__list_projects, tavily-1__tavily_search. No collisions, no confusion.

Both transports

Streamable HTTP and legacy SSE served from the same process. Clients that speak either protocol just work.

Postgres-backed config

Endpoints, namespaces, servers, tool mappings and API keys live in Postgres. The database is the contract.

Embedded admin UI

A full management interface ships inside the binary. Add servers, toggle namespace mappings, test upstream connectivity, manage API keys. No separate frontend to deploy.

From zero to gateway in three commands

  1. 1

    Install

    go build -o bin/submcp ./cmd/submcp, or pull the 15 MB Docker image.

  2. 2

    Configure

    Point it at Postgres, add your upstream servers in the admin UI, and test each one live.

  3. 3

    Connect

    Point any MCP client at /metamcp/all/mcp with an API key. Every tool from every server, one URL.
